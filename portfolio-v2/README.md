# Denzel Ouma Opondo — Portfolio v2

**Live:** https://denzel-ouma-opondo.vercel.app/

This folder contains a source snapshot of the current production Vercel portfolio, including Fikra Connect v3, the interactive sculpted infinity-ribbon 3D module, responsive styles, and the project case studies.

## Technology
- HTML, CSS, ES modules; Three.js from CDN for WebGL.
- Custom parametric infinity ribbon with rounded bronze geometry, studio lights, brushed metal, wire geometry, orbit markers, and pointer / keyboard control.
- Static owner-provided reference image used only when WebGL is unavailable or blocked.
- Fikra Connect is an independently built, subscription-free contact launcher; canonical reusable widget source is in [FikraWorks ecosystem](https://github.com/FikraWorks-Technologies/fikraworks-ecosystem/tree/main/packages/fikra-connect).
- Two Vercel screenshot proxy endpoints live under `api/`.

## Deployment and source-of-truth
The Vercel project was updated with these matching source files through Vercel's deployment API. GitHub is a committed source snapshot, not yet configured to automatically deploy on every push to this project. A future Git integration would need a Vercel project rooted in `portfolio-v2/`.

The original GitHub Pages website is preserved at the repository root for archival access. Portfolio v2 is hosted at the Vercel address above.
